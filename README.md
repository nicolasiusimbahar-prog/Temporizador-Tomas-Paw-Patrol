# Temporizador de Tomás – Paw Patrol

Proyecto pequeño: temporizador visual pensado para Tomás, con colores accesibles, lectura en vivo para lectores de pantalla y persistencia en localStorage.

Características principales
- Interfaz simple con controles Iniciar / Pausar / Reiniciar y ajuste de minutos/segundos.
- Barra de progreso con roles ARIA y actualizaciones en aria-valuenow.
- Mensajes para lectores de pantalla (aria-live).
- Persistencia en localStorage para restaurar estado tras recarga.
- Sonido (WebAudio) y vibración al completar (si el dispositivo lo soporta).

Cómo usar (local)
1. Clona el repo:
   git clone https://github.com/nicolasiusimbahar-prog/Temporizador-Tomas-Paw-Patrol.git
2. Crea la rama y añade archivos (ver instrucciones abajo).
3. Abre `index.html` en el navegador.
